# Shehbaz Pathan

AI Engineer at Opentrons in NYC, working on LLM agents, agent evaluation, and scientific ML.

## Shipping

- **[spectrace](https://github.com/shehbaz0101/spectrace)**: speculative decoding and step verification on agent traces. A step-level verifier rejected 11/11 harmful steps that token acceptance would keep, on 15 synthetic traces. [Live demo](https://spectrace-f6lk.onrender.com)
- **[PINNForge](https://github.com/shehbaz0101/pinnforge)**: physics-informed neural networks for inverse problems. Recovers Burgers viscosity from 32 sparse sensors at 3.4% error vs 34.9% for the closed-form baseline, on 30 hard out-of-distribution cases. [Live demo](https://pinnforge.onrender.com)
- **[Coticula](https://github.com/shehbaz0101/coticula)**: a touchstone bench that tests whether PDE surrogates understand the physics, not just the training data. Its counterfactual exam shows a shipped FNO heat model barely reacts to diffusivity changes while the classical solver does.
